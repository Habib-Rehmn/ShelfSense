# README demo media

- `retail-gaze-annotated.mp4`: the selected annotation video exported from
  `outputs/retail-videos/5_070017_labels.mp4` (640 × 548, H.264, 113 frames).
- `retail-gaze-annotated.gif`: looping 480-pixel-wide preview at 8 FPS, derived
  from that MP4 for inline README playback.

Source: [Retail Gaze](https://www.kaggle.com/datasets/dulanim/retailgaze), session
`5_070017`; annotations from the
[Voxel51 export](https://huggingface.co/datasets/Voxel51/retail_gaze).
Dataset authors: Shashimal Senarath, Primesh Pathirana, Dulani Meedeniya and
Sampath Jayarathna (DASA 2022).

Green overlays visualize dataset annotations, not model predictions. The arrow
origin is a heuristic position in the head box. Playback timing is illustrative.
These two selected media files are included for documentation; the full dataset,
weights and other generated outputs remain ignored.

The original Kaggle publisher currently declares CC0: Public Domain (checked
2026-10-22). See [third-party notices](../../THIRD_PARTY_NOTICES.md) for the metadata
source and the distinction between dataset media and ShelfSense code licensing.
